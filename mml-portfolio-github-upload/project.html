金蝶云星空项目，担任项目助理，参与多组织架构下的企业建模与产品建模配置，协助团队梳理采购转固定资产、委外加工、信用管理等核心业务流程。

通过实践掌握全局共享策略、跨组织成本核算逻辑，以及销售订单至回款、采购付款等业务闭环管理；参与高层会议讨论，协助推动 ERP 功能优化与流程再造。
